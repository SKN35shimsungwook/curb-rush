# Curb Rush

브라우저에서 바로 하는 3D 스트리트 스케이트보드 게임입니다. 차가 다니는 도로, 계단이 있는 광장, 내리막 공원길, 터널이 번갈아 이어지는 코스를 자유롭게 타면서 트릭과 그라인드를 이어 붙여 점수를 쌓습니다.

**바로 하기: https://skn35shimsungwook.github.io/curb-rush/**

## 어떻게 하나요

2분 동안 점수를 겨루는 **세션**과, 시간 제한 없이 타는 **프리 라이드**가 있습니다.

| 동작 | 키보드 | 터치 |
|---|---|---|
| 방향 틀기 | ← → | 화면 왼쪽을 누른 채 좌우로 끌기 |
| 밀기(가속) | ↑ | 자동 |
| 브레이크 | ↓ | 오른쪽에서 아래로 스와이프 |
| 올리(점프) | Space | 오른쪽 탭 또는 위로 스와이프 |
| 킥플립 (공중) | Z | 왼쪽 스와이프 |
| 360 셔빗 (공중) | X | 오른쪽 스와이프 |
| 360 플립 (공중) | Z와 X를 거의 같이 | - |
| 공중 회전 180/360 | 공중에서 ← → | 공중에서 왼쪽 스틱 |

- 내리막에서는 저절로 빨라집니다.
- 레일, 턱, 벤치, 화단 모서리 위로 내려오면 자동으로 그라인드가 걸립니다. 방향키를 세게 누르면 옆으로 내려옵니다.
- 웬만한 장애물은 부딪혀도 밀려나며 속도만 줄어듭니다. 넘어지는 경우는 아래 셋뿐이고, 넘어져도 잠시 뒤 그 자리에서 다시 탑니다.
  - 달리는 차에 치였을 때
  - 세워진 차에 정면으로 빠르게 박았을 때
  - 트릭이나 회전을 너무 덜 끝내고 착지했을 때
- 트릭은 65%만 돌아도 "Sketchy"로 인정되고, 착지 직전에 딱 맞춰 끝내면 PERFECT 보너스(×1.5)가 붙습니다.
- 한 번에 이어 붙인 트릭 수만큼 점수에 곱하기가 붙습니다.

## 만든 과정

처음에는 예전에 해 본 스트리트 스케이트 게임처럼 만들고 싶었는데, 남의 게임을 그대로 베끼는 대신 그 시절 로우폴리 그래픽 느낌만 살리고 이름, 캐릭터, 맵은 새로 만들었습니다.

- 3D 모델링 툴 없이 Three.js 기본 도형(상자, 원통, 구)만으로 스케이터, 자동차, 건물을 조립했습니다.
- 아스팔트, 보도블록, 건물 창문 텍스처는 이미지 파일 없이 캔버스에 직접 그렸습니다.
- 효과음과 드럼 루프도 음원 파일 없이 Web Audio로 합성했습니다.
- 코스는 40m 단위 구간을 앞에 계속 이어 붙이는 방식이라 끝없이 달릴 수 있습니다. 구간마다 메시를 재질별로 합쳐서 휴대폰에서도 버티게 했습니다.
- 첫 버전은 3차선만 오가는 러너 방식이었는데, 직접 해 보니 스케이트 타는 맛이 없었습니다. 그래서 예전 게임 플레이 영상을 보며 포맷을 다시 잡았습니다. 방향을 자유롭게 틀고, 밀어서 가속하고, 구역이 바뀌는 코스를 타는 방식으로 바꿨습니다.
- 빌드 도구 없이 HTML 하나와 JS 모듈로만 되어 있어서 GitHub Pages에 그대로 올릴 수 있습니다.

## 배운 점

- 스케이트 게임은 보드를 진짜 물리 엔진에 맡기면 조작이 거의 안 됩니다. 상태(주행, 공중, 그라인드, 넘어짐)를 나누고 움직임을 직접 계산하는 편이 손맛을 맞추기 훨씬 쉬웠습니다.
- 너무 쉽게 넘어지면 재미가 없어서, 부딪히면 밀려나기만 하고 넘어지는 조건은 꼭 필요한 것만 남겼습니다.
- 계단 난간은 내려가는 기울기 때문에 점프한 스케이터와 높이가 잘 안 만나서, 레일 위 일정 높이 안으로 내려오면 끌어당기는 자동 그라인드를 넣어야 했습니다.
- 사람이 직접 해 보기 전에 자동으로 달리는 봇을 돌려서 충돌, 그라인드, 계단 판정을 먼저 검증했습니다.

## 실행

```bash
python -m http.server 5173
```

브라우저에서 `http://localhost:5173`을 엽니다. 주소 뒤에 `?debug`를 붙이면 콘솔에서 `curb` 객체로 상태를 볼 수 있습니다.
